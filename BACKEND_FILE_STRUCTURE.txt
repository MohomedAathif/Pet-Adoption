🚀 QUICK START

1. Install dependencies:
   pip install -r requirements.txt

2. Configure environment:
   cp .env.example .env
   # Edit .env file

3. Initialize database:
   python -m app.init_db

4. Run server:
   python -m uvicorn app.main:app --reload

5. Test API:
   Visit: http://localhost:8000/docs
