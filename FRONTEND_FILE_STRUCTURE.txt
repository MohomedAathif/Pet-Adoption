🔧 TO ADD NEW FEATURES
──────────────────────

Add New Page:
1. Create component in src/components/pages/
2. Import in App.jsx
3. Add <Route> element
4. Add menu item in Sidebar.jsx

Customize Colors:
1. Edit tailwind.config.js
2. Or use Tailwind color utilities

Change Layout:
1. Modify Layout.jsx
2. Adjust responsive classes

Add Components:
1. Create in src/components/common/
2. Import where needed
3. Use Tailwind classes
